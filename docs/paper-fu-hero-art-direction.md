# Paper-Fu Phase 2A hero art direction

## Shared visual grammar

- Original layered paper dioramas, not screenshots or generic game concept art.
- Warm ivory paper desk as the base, with ink-blue structure, charcoal ink, ember-red action marks, brass certification details, and restrained teal/green only for narrow guard semantics.
- Visible cut edges, paper fibers, tape tabs, staples, rubber stamps, registration marks, clipped shapes, and offset shadows.
- Strong silhouettes and readable subject grouping at thumbnail size.
- No baked-in words, labels, logos, watermarks, or pseudo-text. UI typography owns all copy.
- No neon, glossy glass, cyberpunk, photo-realism, or arbitrary decorative noise.
- Action should feel like “HIYAH!” energy held inside a deadpan municipal filing system.

## Composition rules

- Home hero: strongest ensemble scene, with the action weighted right and calm negative space left.
- Route headers: one clear scene or prop system, weighted right so the section title remains legible on the left.
- Rules/chapter images: visual metaphor for the chapter, one focal action, restrained background, no tiny unreadable details.
- Every asset must still read when cropped by `object-fit: cover` on desktop, tablet, and mobile.

## Phase 2A asset set

- Home hero: field test / fighters / inspector / filing cabinet.
- Route headers: backstory, quick start, rules, card library, rulings, glossary.
- Chapter images: components, modes, setup, stats, round, timing, combat, equipment, market, belts, characters, tag team, boss, priority, endgame.

The asset pass changes only presentation. Routes, copy, card IDs, rules data, structured effects, and gameplay behavior remain untouched.
